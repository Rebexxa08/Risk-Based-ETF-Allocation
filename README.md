# Risk-Based ETF Allocation

## Project Overview

This project investigates whether risk-based ETF allocation strategies can achieve superior risk-adjusted performance compared with a traditional 60/40 portfolio.

The project is developed in Python and includes historical data processing, portfolio construction, backtesting, and risk analysis.

## Research Question

Can risk-based ETF allocation strategies outperform a traditional 60/40 portfolio on a risk-adjusted basis?

## Methodology

The project will compare several allocation approaches, including:

- Traditional 60/40 portfolio
- Inverse Volatility allocation
- Minimum Variance allocation
- Risk Parity allocation

Performance and risk will be evaluated using metrics such as annualized return, volatility, Sharpe ratio, maximum drawdown, and Value at Risk.

## Technology

Python, pandas, NumPy, SciPy, yfinance, Plotly.

## Project Structure

- `data/` — Historical ETF data
- `src/etf_risk_allocation/` — Data processing, strategies, backtesting, and risk analysis
- `notebooks/` — Exploratory analysis
- `tests/` — Unit tests
- `reports/` — Figures and results
